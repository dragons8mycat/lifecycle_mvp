Sales Matrix Prototype

Full lifecycle matrix with named catalogue data and a hidden drawer

This prototype is intentionally literal. The industry selector is fixed to `Solar` and `Housing`, project jurisdiction supports visible multi-select with a `GB` option, the header uses the full corporate lifecycle, every matrix cell shows the actual catalogue data name plus geometry, and the right-hand panel stays closed until a data touchpoint is clicked.
